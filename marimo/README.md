# marimo Patterson法・Niederreiter型の実験

`marimo/` には、有限体演算とGoppa符号に関する実験コードがあります。
このデモでは、次の一連の処理を確認します。

1. Goppa多項式 `g` とBM法用の検査行列 `H` を生成する。
2. 指定したハミング重みの誤りベクトル `e` を作る。
3. 必要に応じて行と列をスクランブルし、`H_pub = A * H * P` を作る。
4. 暗号文シンドローム `c = H_pub * e` を計算する。
5. 秘密の逆行列 `A^-1` で行スクランブルを戻し、BMシンドロームをPatterson形式に変換して復号を試みる。
6. 復号した誤り位置と誤り値を、元の誤りベクトルと比較する。

また、シンドローム変換の結果が、誤り位置から直接計算したPattersonシンドロームと一致することも検査します。
`K`、`M`、`Pr`、`E` は `global-p.h` で定義されるコンパイル時パラメータです。
現在の設定では `K=16` のため、デモの既定の誤り重みも16です。

## デモのビルドと実行

リポジトリのルートディレクトリから実行します。

```sh
make -C marimo niederreiter_demo
./marimo/niederreiter_demo
```

第1引数で誤り重みを指定できます。指定できる範囲は1から `K` までです。
通常モードでは、ランダムな可逆行列による行変換とランダムな列置換を行います。

```sh
./marimo/niederreiter_demo 8
```

第2引数に `raw` を指定すると、スクランブル前の検査行列をそのまま使い、
列置換も恒等置換にします。

```sh
./marimo/niederreiter_demo 16 raw
```

出力には次の情報が含まれます。

- 暗号文シンドロームと、復号器に渡すBMシンドローム
- 変換後のPattersonシンドロームの係数
- BM復号器の誤り位置多項式の次数、根の数、シンドロームとの整合性、元の誤りとの一致
- BM側の列番号、注入した誤り値、BM多項式の根、対応するPatterson位置、Patterson復号結果の比較表
- Patterson復号器が見つけた候補数と、元の誤りベクトルを復元できたかどうか

スクランブルありのモードでは、BM側の列番号とPatterson側の位置番号は通常異なります。
比較表では列置換による対応を表示します。`raw` モードでは両者の位置番号が同じです。

このデモでは、同じBMシンドロームにBM復号とPatterson復号の両方を適用します。
BM復号は長さ `K` のシンドローム列から誤り位置多項式を求め、その根を誤り位置として調べます。
現在の `K=16` では、通常のBM復号の訂正範囲は最大 `K/2=8` 個です。
デモで作る誤り値はすべて1なので、BMの比較は誤り位置（サポート）の一致を調べています。
BM多項式の根は候補位置であり、特に訂正範囲を超えた場合は実際の誤り位置とは限りません。
`BM decoded support matches syndrome` が `yes` の場合にだけ、根の集合が入力シンドロームと整合します。
`BM original error recovered` は根の集合が注入位置と完全一致したことを示します。

プログラムの終了コードは従来どおりPatterson復号の結果に基づきます。Patterson復号候補が
元の誤りベクトルと一致すれば0、一致しなければ0以外です。BM復号の成功・失敗は出力で別に確認してください。
1回の実行で成功しても、すべての誤りベクトルや鍵で復号が成功する保証にはなりません。

## 代表的な実行結果

2026-11-02に `./marimo/niederreiter_demo 16 raw` を実行した一例です。
`raw` モードで重み16（`K=16`）の誤りを入れたところ、BM復号は誤り位置を復元できず、
得られた根の集合もシンドロームと一致しませんでした。一方、同じシンドロームをPatterson用に
変換して復号すると、注入した誤りと一致する候補が1つ見つかりました。

```text
Niederreiter-style demo: K=16, error weight=16, mode=raw (no A/P scramble)
BM decoder locator degree: 8 (unique-decoding limit K/2=8)
BM locator roots (not necessarily valid errors): 1
BM decoded support matches syndrome: no
BM original error recovered: no
candidate 1 matches injected errors: yes
Patterson candidates: 1
original error recovered: yes
```

この出力は「この鍵・この誤りではBM復号に失敗し、Patterson復号では復元できた」一例を示します。
鍵と誤り位置は実行ごとにランダムに生成されるため、根の数などのBMの詳細出力は実行ごとに変わります。
この一例から、重み16なら必ず同じ結果になる、またはPattersonが常に復元できるとは結論できません。

## Patterson復号成功率の実験

`patterson_q.c` の `patterson_experiment()` は、複数の誤りベクトルを試し、
誤り重みごとに結果を集計します。有限体のテーブルを初期化した後、
`vmo.c` の `main()` から、たとえば通常のデモの代わりに次のように呼び出します。

```c
int main(void)
{
    srand((unsigned)time(NULL));
    mkmf();
    makefg();
    de();

    patterson_experiment(1, K, 1, 100, 1, 1);
    return 0;
}
```

関数の引数は次のとおりです。

```c
patterson_experiment(wmin, wmax, ng, trials, maxval, phimax);
```

| 引数 | 意味 |
| --- | --- |
| `wmin`, `wmax` | 試す誤り重みの最小値と最大値。`wmax` は `K` 以下に制限されます。 |
| `ng` | 生成するGoppa多項式（鍵）の数。 |
| `trials` | 各誤り重み・各鍵で試す誤りベクトルの数。 |
| `maxval` | 誤り値を `1..maxval` から選びます。`1` は誤り値をすべて1にし、`Pr-1` は基礎体の0以外の値から選びます。 |
| `phimax` | 復号器が試す `phi` の最大値。`maxval=1` なら1、一般の非零誤り値を使うなら `Pr-1` を指定します。 |

集計結果の列は次の意味です。

- **成功**: 元の誤りベクトルが唯一の復号候補だった。
- **曖昧**: 元の誤りベクトルは候補に含まれるが、候補が複数あった。
- **失敗**: 元の誤りベクトルが候補に含まれなかった。
- **スキップ**: シンドロームが `g` を法として可逆でない場合など、復号器が負の状態を返した。

この実験関数は乱数シードを設定しません。再現可能な実験にする場合は、
呼び出し側で `srand()` を設定してください。また、現在の復号器は試行ごとに
シンドロームの診断情報を出力するため、試行回数を増やすと出力が大量になります。

## 適用範囲と注意

このコードは研究・学習用の実験であり、実用暗号ではありません。
デモは暗号学的に安全な乱数生成器ではない `rand()` を使用し、任意メッセージの符号化や
完全なKEM・暗号化プロトコルも実装していません。サンプル入力で復号できたことは、
その入力に対する動作確認であり、暗号学的安全性や一般的な復号保証を示すものではありません。
